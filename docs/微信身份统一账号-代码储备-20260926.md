## 2026-10-09 登录受限整改

- 正常启动无有效会话时直接浏览公开活动库与精彩案例；有有效会话仍经 `/me` 复核后自动进入工作台。仅主动选择主办方工作台或资料下载才进入密码登录页，账号申请默认收起。
- `/api/auth/capabilities` 只返回密码和微信登录能力布尔值，不返回密钥或身份。微信入口初值关闭、请求失败关闭；配置存在不等于真实 code2Session 或真机联调已通过。
- 活动和案例登录后仅可回到程序白名单中的原详情，移除 `guest=1` 并重新读取权限；外部网址、管理页及任意附加参数不作为回跳目标。
- 总部账号管理新增 `albumReadScope` 与 `albumReadProjectIds`。历史未设置账号默认 `all`，不批量改变现有业务；总部管理员始终全部可见。`own-and-selected` 只允许读取本人创建和总部指定的内部相册，列表和详情均由服务端过滤；指定查看不会授予修改、上传或删除权限。改变权限会撤销该账号现有会话。
- 已开放公开分享仍是持有链接访问单个相册，不增加匿名相册列表或跨相册入口。内部查看范围不是撤回既有公开分享的机制；若需要撤回公开访问，须按原相册分享开关处理。
- 审核可使用提前启用的普通 `member` 账号及 `canDownload=true`，并设置仅本人和指定的授权演示相册；不提供总部管理员凭据，不创建审核绕过。创建账号、演示素材和提审辅助信息须由总部安排，不把密码写入仓库、小程序包或公开页面。本次代码发布不创建/改动真实账号或素材，不自动提交审核或正式发布。

## 唯一账号原则

业务身份只用原 `users.id`。`wechat_identities` 用 `(appid, openid)` 唯一定位微信身份、`(appid, user_id)` 唯一限制一个平台账号只绑定一个该小程序微信。相册 `ownerId`、角色、停用、SOP 下载都继续读取这个 `users.id`，不新建第二套用户库，也不按昵称、自填手机号或机构名自动合并。`wechat_identity_events` 保留申请、绑定、审批、拒绝、解绑、重开的记录；前端和总部列表只看到微信核对码，不得到完整 OpenID、AppSecret 或 session_key。

小程序遵循[微信官方登录流程](https://developers.weixin.qq.com/miniprogram/dev/framework/open-ability/login.html) `wx.login → 服务端 code2Session → OpenID → 本平台登录态`。一次性 code 每次请求重新取得；AppSecret 只读服务端环境变量 `WECHAT_MINIAPP_SECRET`，AppID 默认 `wx58bef83060b92027`，可用 `WECHAT_MINIAPP_APPID` 显式覆盖。未配置密钥时微信接口返回 503，原 H5 账号密码登录仍可用。

## 用户与总部操作

1. 首次选择登录并成功后保存平台登录态（不保存密码）。再次启动或恢复前台先调用 `/me` 复核；有效则默认直接进工作台，不重复显示登录选择。只有此前主动微信登录或绑定成功、非总部管理员、原会话仍有效且距到期不超过 24 小时时，才可带原 Bearer 与新微信 code 静默续验；服务端必须核验同一账号及当前绑定，新的登录态仍为 7 天。原会话已到期、权限撤销或身份无法复核时，不依靠本地日期或昵称自行恢复，须重新选择认证；未绑定微信及总部的密码会话不自动延长。主动退出立即取消本机自动恢复，晚到的异步结果不得重新登录。
2. 未登录时提供独立的平台账号密码登录和用户主动选择的微信登录。启动或密码登录不自动绑定微信；游客可选择暂不登录，预览活动库和精彩案例，但下载需登录并获得总部授权。已绑定微信者主动点击微信登录后，服务器核验 code，找到已启用的同一 `users.id` 后发平台 token；被停用的账号不能取 token。
3. 有原 H5 账号的主办方：明确选择绑定已有账号，再验证原平台账号密码。密码不是微信密码。一个微信不能绑多个平台账号，一个平台账号不能绑多个此小程序微信；冲突时停下找总部，不创建新账号。总部管理员仍使用原平台账号密码，有效会话同样默认进入；普通申请不能匹配总部管理员账号。用户已确认“后台管理员”指审核、匹配和权限控制，不是指定日期操作或开通总部微信免密绑定。
4. 全新主办方：在小程序提交真实姓名、联系方式、城市、机构。`pending` 状态不给平台 token，也不能上传、删除或管理相册。客户从分享卡片进入公开相册仍免登录。
5. 总部在“账号权限 → 微信小程序申请”逐条核实：若有已启用或 H5 待审账号，选该原账号 ID；若确无原账号，勾选确认后创建新平台用户，指定 `viewer/member/operator` 及 SOP 下载权限。`member`、`operator` 可以新建本人相册，`viewer` 不能。申请人不能给自己指定角色；通用申请流程不能给总部管理员授权。
6. H5 申请改为单独 `pending`，填写联系方式供人工核对；如果同一人两端都申请，可在总部把微信申请绑定到那条 H5 待审用户并同时启用，保留 H5 密码、账号与 `users.id`。旧 `disabled` 不自动认定为待审，也不再提供“全部通过”。拒绝留状态记录而非删除。
7. 总部可解除微信绑定并撤销该账号当前会话，必要时重新开放申请。WX 新建的账号没有默认 H5 密码；若要登录 H5，总部在同一用户卡片首次设置 H5 账号/密码，保留已批准微信绑定，不新建第二个用户 ID。已有密码的重置则撤销微信绑定，待总部重新核实。

## Claude 审阅后的本地安全补丁（仍未上线）

- 首次补建 H5 密码与已有密码重置明确区分。已有密码重置会撤销该用户旧会话和已批准的微信绑定；若解绑数据库操作异常，先持久化微信登录阻断标记，失败时保持拒绝登录。角色或账号状态变化也会撤销旧会话，避免停用后重新启用时旧 token 复活。绑定、审批及账号更新共用写锁，跨异步请求复核账号授权快照，不能用重置前的凭据恢复登录。
- Cookie 授权的写请求只接受明确受信的 H5 页面来源；默认受信域名是 `https://proj2.likeduoduiyi.cn` 与 `https://apip2.kkhuacai08.cn`。其他正式 H5 域名应经核实后设置 `SILVER_TRUSTED_WEB_ORIGINS`（逗号分隔的完整 Origin）；小程序 Bearer 请求不依赖浏览器 Origin。不要把任意通配域名加入配置。
- H5 待审账号用正确密码尝试小程序绑定时明确提示待审，不累积密码失败次数。总部管理员不得自绑微信免密进入；原账号密码登录仍保留。
- 总部每张用户卡片显示当前微信绑定和解除入口，不受“最近处理记录”条数限制；小程序申请页显示与总部一致的 12 位核对码，但仍需人工核实申请人。
- 尚未处理：误新建账号后的相册归属转移须设计显式总部修复流程，不能自动按姓名/手机号合并；SOP PDF 并发生成建议加内容版本缓存；“关闭分享”对其他已登录账号的可见范围等待业务决定。以上不能被本地安全补丁误报为已解决。
