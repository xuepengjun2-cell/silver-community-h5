# 微信身份与平台账号统一接入（代码储备）

状态：仅本地开发分支，未配置真实 AppSecret，未发布服务器、静态页面或小程序体验版。不得把本地编译/假微信测试当作真机验收。

## 唯一账号原则

业务身份只用原 `users.id`。`wechat_identities` 用 `(appid, openid)` 唯一定位微信身份、`(appid, user_id)` 唯一限制一个平台账号只绑定一个该小程序微信。相册 `ownerId`、角色、停用、SOP 下载都继续读取这个 `users.id`，不新建第二套用户库，也不按昵称、自填手机号或机构名自动合并。`wechat_identity_events` 保留申请、绑定、审批、拒绝、解绑、重开的记录；前端和总部列表只看到微信核对码，不得到完整 OpenID、AppSecret 或 session_key。

小程序遵循[微信官方登录流程](https://developers.weixin.qq.com/miniprogram/dev/framework/open-ability/login.html) `wx.login → 服务端 code2Session → OpenID → 本平台登录态`。一次性 code 每次请求重新取得；AppSecret 只读服务端环境变量 `WECHAT_MINIAPP_SECRET`，AppID 默认 `wx58bef83060b92027`，可用 `WECHAT_MINIAPP_APPID` 显式覆盖。未配置密钥时微信接口返回 503，原 H5 账号密码登录仍可用。

## 用户与总部操作

1. 已有平台会话：启动时先调用 `/me` 复核；有效则直接进工作台。
2. 已绑定微信：服务器核验微信 code，找到已启用的同一 `users.id` 后发平台 token；被停用的账号不能取 token。主动退出后不自动立刻重登。
3. 有原 H5 账号的主办方：首次输入账号密码绑定此微信。一个微信不能绑多个平台账号，一个平台账号不能绑多个此小程序微信；冲突时停下找总部，不创建新账号。
4. 全新主办方：在小程序提交真实姓名、联系方式、城市、机构。`pending` 状态不给平台 token，也不能上传、删除或管理相册。客户从分享卡片进入公开相册仍免登录。
5. 总部在“账号权限 → 微信小程序申请”逐条核实：若有已启用或 H5 待审账号，选该原账号 ID；若确无原账号，勾选确认后创建新平台用户，指定 `viewer/member/operator` 及 SOP 下载权限。`member`、`operator` 可以新建本人相册，`viewer` 不能。申请人不能给自己指定角色；通用申请流程不能给总部管理员授权。
6. H5 申请改为单独 `pending`，填写联系方式供人工核对；如果同一人两端都申请，可在总部把微信申请绑定到那条 H5 待审用户并同时启用，保留 H5 密码、账号与 `users.id`。旧 `disabled` 不自动认定为待审，也不再提供“全部通过”。拒绝留状态记录而非删除。
7. 总部可解除微信绑定并撤销该账号当前会话，必要时重新开放申请。WX 新建的账号没有默认 H5 密码；若要登录 H5，总部在同一用户卡片设置 H5 账号/密码，不新建第二个用户 ID。

## 上线前硬性检查

- 备份 MySQL 与当前代码；核对现网 `users` 中历史 `disabled` 账号，人工区分停用与旧待审，不批量激活或自动迁移。校验新表创建权限及唯一索引。
- 在服务端安全注入 AppSecret，不放在仓库、聊天、小程序包、浏览器或日志；微信用户联系资料的收集和保存须反映在小程序隐私保护指引中。
- 后端、H5 后台与小程序版本要成套发布；单独更新 H5 后台会请求新审核接口。先体验版联调，再考虑正式版；小程序页面、视频上传和公开相册均需回归。
- 四类账户真机验收：微信未申请、待审、已批准、已停用/解绑；再用已有 H5 主办方、另一位主办方、只读、总部管理员验证相册创建者权限、活动 PDF 与案例下载。验证 iPhone、安卓及原匿名分享链路。
- H5 浏览器目前使用账号密码，但已经共享 `users.id`、申请状态和总部审核。若将来要求“微信内 H5 自动登录”，须另外确定网页授权主体与凭据；小程序 `wx.login` 不能直接当成网页 OAuth。完成该产品选择前，不在 H5 页面伪造微信登录按钮。

本地验证：`npm run check`、`npm run test:identity`、`npm run test:media`、`npm run test:sso`、`npm run test:concurrency`。其中微信联调使用假 code2Session/MySQL；真实 AppSecret、真实 MySQL 迁移、微信开发者工具编译和真机体验尚待上线前执行。
