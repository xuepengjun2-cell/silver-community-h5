# 活动 SOP 单点进入发布说明（2026-09-05）

## 基线与范围

- 本分支以 `silver-new:/var/www/silver-community-h5` 的当前生产源码为发布基线，避免用 GitHub 旧版覆盖线上多图上传、共创审核、角色控制与素材功能。
- 不包含生产数据、会话文件、上传素材、备份文件或环境变量。
- 新增接收端 `/api/auth/sso`、短时票据校验、一次性票据表和前端首屏票据消费。

## 身份与权限流程

1. 视频号助手总部签发 120 秒有效的 HMAC-SHA256 短时票据，票据放在 URL fragment 中，不传递密码或 Cookie。
2. 活动平台前端只消费一次 fragment，调用 `/api/auth/sso` 后立即从地址栏清除票据。
3. 服务端校验签名、签发方、接收方、有效期、账号有效期与唯一 `jti`；重复票据返回 409。
4. 已有绑定账号沿用活动平台原权限；首次进入的总部账号仅创建最低权限 `member`；同名、停用或身份冲突时拒绝自动恢复。
5. 活动平台创建独立会话，最长 7 天且不得超过视频号助手账号有效期。

## 必要配置

- 视频号助手总部和活动平台必须配置同一份 `ACTIVITY_HUB_SSO_SECRET`（至少 32 字符）。
- 视频号助手 `ACTIVITY_HUB_BASE_URL=https://proj2.likeduoduiyi.cn/silver/`。
- 可选 `ACTIVITY_HUB_SSO_USER_MAP` 用于把特定总部账号映射到已有活动平台账号；未配置时按上述最低权限规则首次创建。

## 验证门槛

- `npm run check`
- `npm run test:sso`
- 生产 `/silver-api/health` 返回数据库健康。
- 无效签名返回 401、重复票据返回 409、首次有效票据创建 `member` 会话、原密码登录仍可用。
- 视频号助手端只有探测到配置完整时才显示入口；免密失败时右上角明确提示且不影响回复任务。
