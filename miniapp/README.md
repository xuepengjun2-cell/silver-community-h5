# 活动相册 · 个人主体微信小程序开发版

AppID：`wx58bef83060b92027`。这是与银发社群 H5 共用数据和主办方账号的原生小程序开发工程，不使用 `web-view`，不存 AppSecret、TOS 密钥或密码。

## 双入口

- 主办方：正常启动 → 用原 H5 账号/密码登录 → 工作台（我的活动相册、活动库、精彩案例）→ 新建活动、编辑资料、上传素材 → 直接转发小程序卡片。无需复制或粘贴 H5 链接。
- 客户：点击某个相册的分享卡片 → 匿名查看该相册、照片和视频；符合交付格式的素材可保存到系统相册。分享路径指向 `pages/album/index?id=...`，不经过主办方登录。
- 活动库和精彩案例已改为封面卡片，详情按活动概览、亮点、时间轴、执行 SOP、参考素材及案例素材分类展示；“分享”发送带封面的原生小程序详情卡片，不是让接收者复制文字链接。客户可以免登录看已发布的案例/活动预览；完整 SOP 仍需主办方登录，案例素材下载仍按原 H5 权限。原 H5 的编辑/审核、评论、SOP 导出、案例文档/外链下载及总部权限/访问日志尚未迁入，不能称“整个 H5 后台已完整迁移”。

## 客户保存的实际边界

- 小程序相册和单素材分享可匿名打开；点击“保存到手机相册”后，先复核相册仍已发布且允许分享，再经现有公开接口记录下载，随后从已登记的项目 CDN 下载并调用微信保存照片/视频接口，不把临时 TOS 签名地址展示给客户。
- 只有项目 CDN 上的 JPG/PNG 和有明确文件大小、且不超过 200 MB 的 MP4，才显示为可直接保存。MOV/HEIC/SVG 等原件不能据此宣称可一键保存；按钮会说明原因。新上传视频需等服务端交付版转码接口上线，旧素材需补交付版。
- 2026-09-22 只读核对现网一个已发布相册：1 张 JPG、36 个视频，其中仅 2 个 MP4，其余 34 个为 MOV。1 张照片和 2 个 MP4 的 CDN `HEAD` 返回 200、类型与长度正确；这只证明交付文件可访问，**尚不等于已在 iPhone/安卓/鸿蒙真机完成保存验收**。

## 新上传的处理边界

1. 小程序 `wx.chooseMedia` 选择照片/视频后，本机调用 `wx.compressImage` / `wx.compressVideo`；视频压缩后仍超过 190 MB 时，明确要求分段，不上传原片。
2. `wx.uploadFile` 向后端新增的鉴权入口上传压缩后的临时素材；上传域名必须在该 AppID 后台单独配置。服务端串行转码：照片统一 JPEG；视频统一 H.264/AAC MP4、720p 上限、25 fps、`faststart`，目标约 155 MB，最终严格小于 190 MB，最长 40 分钟。时长过长/码率过低/输出不合格时拒绝发布，并提示分段。
3. 转码成功后才上传 TOS、校验对象大小并将媒体写入相册；视频任务有鉴权状态查询。服务端临时源文件在完成或失败后删除，新的小程序上传不保存云端原视频。旧素材以及 H5 上传仍按原流程保留原件，不做批量删除。
4. 服务端依赖 `ffmpeg`/`ffprobe` 和 TOS，单队列处理以保护服务器。已只读确认现网服务在 `silver-new` 的 PM2 `silver`，其 `server.js` 和 `package.json` 与本开发分支起点一致，节点具备 FFmpeg/FFprobe、约 6.1 GB 可用磁盘；但仍未用真实样本完成画质/耗时/真机验收。
