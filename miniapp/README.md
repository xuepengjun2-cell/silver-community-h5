# 活动相册 · 个人主体图文版

AppID：`wx58bef83060b92027`。与银发社群 H5 共用数据和平台账号，使用原生页面，不使用 `web-view`，包内不放密码、AppSecret 或 TOS 密钥。

## 本版能力

- 活动 SOP：公开图文介绍、参考图片；完整方案和 PDF 按平台账号权限提供。
- 精彩案例：图片与可打开的办公文档。照片保存、文档下载先登录并经服务端授权与审计；游客图片预览禁用长按菜单。
- 活动照片相册：主办方按原权限创建、编辑、上传压缩照片、删除照片和分享相册；客户可免登录打开已发布、允许分享的指定相册并保存 JPG/PNG。
- 图片上传：仅选择图片，手机端真实调用 `compressImage`，只上传压缩后的临时文件；文件大小不超过 50MiB。后台仍验证实际格式。选择前锁定操作，断网提示可重试，离页或换账号后晚到的选择、压缩、请求响应不能更新原页面。
- 所有角色使用同一份图文能力。小程序不提供视频选择、压缩、上传、播放、截帧封面、保存、任务重试、视频直达或外部链接替代入口，没有审核专用开关或远程恢复开关。

已有分享和混排相册按原始素材编号定位照片；上一张/下一张跳过不支持的素材。旧分享如果直接指向不支持的素材，显示不可用，不播放、不下载、不跳转。图片保存与删除保持原始索引，避免处理错文件。所有页面数据仅投影本版使用的字段，封面必须是图片。后台支持的 WebP/GIF/SVG 图片仍可预览和管理，系统相册保存限定 JPG/PNG。

本次修订不删除客户已有视频，不改变 H5/后台的视频处理和大小标准；服务端共享 API 可以继续向网页提供既有数据。相关服务端回归保留于仓库根目录 `tests/`，不编入小程序包。历史视频标准见仓库根目录 `VIDEO_UPLOAD_STANDARD.md`，不是本小程序的可用能力。

## 账号和权限

默认无会话进入公开活动与案例，不强制登录，不自动获取微信身份。有效会话经服务端复核后进入工作台。相册分享绕过主办方登录；案例下载与相册分享保存是不同授权范围。

显式登录页保留平台账号密码登录、申请平台账号，以及服务端已配置时可选的微信身份登录/绑定。申请资料仅供总部人工核实，成功申请不建立工作台会话；联系方式由申请人填写，不表示已获微信手机号认证。不自动调取头像、手机号，不按姓名/联系方式自动合并账号。微信身份绑定仍保留原 `users.id` 和权限。

服务端按角色和创建者授权：总部管理全部；主办方只能修改自己的相册；只读账号不能创建、上传或删除。不能仅靠隐藏按钮代替后台鉴权。主动退出清除本地会话；晚到的登录结果不能恢复退出状态或覆盖另一个账号。
