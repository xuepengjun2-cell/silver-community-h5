# 活动相册 · 个人主体微信小程序开发版

这是现有银发社群活动相册的 **C 端原生小程序**。B 端仍在现有 H5 后台创建、发布相册并上传照片/视频；客户通过小程序分享卡片看相册，点击“保存到手机相册”，不要求注册、手机号或账号密码。没有 `web-view`、支付或微信登录。

## 当前已做

- 主办方粘贴已发布的 H5 相册分享链接，打开小程序相册并转发小程序卡片；后续客户直接点卡片进入，无须粘贴链接。
- 匿名获取已发布、分享开启的相册，展示照片/视频，打开单个素材并分享。
- 保存前重新检查公开状态和素材；沿用原下载接口记录下载，随后经本项目 CDN 下载本地临时文件，用微信原生接口保存到系统相册。用户拒绝相册权限后可从设置开启并重试。
- 对 MOV、WEBM、超过 200 MB 的视频明确说明由主办方补传适合保存的 MP4；不提供假装可保存的按钮或一串下载地址。
- 客户端已预留 `media[].delivery = { url, size }`：服务端以后生成 MP4 交付版时，原 `media.url` 继续用于预览，保存改用交付版；必须由服务端在公开相册响应中下发同一项目 CDN 域名的真实 URL 和字节大小。

## 导入和测试

1. 使用微信开发者工具导入此目录。`project.config.json` 已绑定您提供的 AppID `wx58bef83060b92027`；AppID 本身不能证明个人主体认证状态或审核权限，需要在该小程序后台核实。不要在代码里放 AppSecret。
2. 在小程序后台给该 AppID 配置 HTTPS `request` 合法域名 `apip2.kkhuacai08.cn`，以及 `downloadFile`/媒体使用的域名 `proj2.likeduoduiyi.cn`，按后台实际分类和域名校验结果设置。不要为了上线长期关闭域名校验。
3. 小程序后台设置真实的服务类目、备案和隐私保护指引，并说明只在点保存时申请“添加到相册”权限。**个人认证不等于类目和代码审核自动通过**；现有“B 端上传、C 端公开分享”的实际业务须如实向微信申报。若个人主体无法匹配类目或无法绑定现有域名，应改用合适的非个人主体，不要用不相关类目试审。
4. B 端在网页后台发布相册并复制原相册分享链接；在小程序首页粘贴打开，点“分享相册给朋友”发送原生小程序卡片。
5. 用 iPhone 微信真机验证：照片与 MP4 小于 200 MB 保存到系统“照片”；首次授权/拒绝后重新授权；MOV/大于 200 MB 的提示；关闭分享后无法打开和继续保存；下载统计回读。安卓/鸿蒙也需真机回归。

## 正式运营前仍需完成

- 抽查线上一册：36 个视频中 34 个为 MOV、24 个超过 200 MB，当前只有 2 个 MP4 可直接保存。上传允许最高 2 GB，而微信 `wx.saveVideoToPhotosAlbum` 仅支持 MP4、`wx.downloadFile` 单次上限 200 MB。需在服务端异步生成 **小于 200 MB 的 MP4 交付版**、校验实际大小与可播放性、保留原片，并将 `delivery` 随公开相册响应返回；当前服务端尚未产生该字段，不能宣称旧视频全部可保存。过长视频如压缩后画质不可接受，需要设计分段交付，不能靠客户端绕过限制。
- 现有图片/视频地址来自公开 CDN，关闭分享后公开详情和下载接口会拒绝访问，但已泄露的原始 CDN 地址不能被彻底撤销。若相册包含敏感肖像或要求强撤销，应改为具备有效期/鉴权的同域下载分发，而非仅靠小程序页面隐藏。
- AppID 所属账号的个人主体认证状态、业务域名核验、类目/备案/隐私审核、微信真机验收与正式分享二维码，均需要账号持有人配合。当前代码**未发布**，也未修改生产环境。
