# 活动相册 · 个人主体微信小程序开发版

AppID：`wx58bef83060b92027`。这是与银发社群 H5 共用数据和主办方账号的原生小程序开发工程，不使用 `web-view`，不存 AppSecret、TOS 密钥或密码。

## 公开浏览与主办方入口

- 默认首页：有效平台会话经服务端复核后自动进入主办方工作台；没有会话或会话已失效时直接浏览公开活动库与精彩案例，不先展示登录表单、不索取微信身份。临时断网时保留原 token，但只进入公开浏览，不假定该会话已核验。公开首页顶部的“主办方登录 / 申请账号”以及受限操作点才进入显式登录页 `pages/entry/index?mode=login`，不会强制所有访客登录。通用分享直接进入公开首页；单个活动、案例继续直达同一条公开详情。
- 主办方：显式登录页以平台账号密码为主入口，账号与网页工作台共用，密码不是微信密码。可选微信入口默认不显示；公开接口 `GET /auth/capabilities` 仅在服务端返回 `capabilities.wechatLogin === true` 时展示，接口失败、旧服务端尚未提供或请求未结束都不阻塞密码登录、平台申请与公开浏览。这个布尔值仅表示配置齐备，仍需真实微信联调验收。用户主动点击“使用微信登录”后，取得一次性 code，由服务端换取微信 OpenID；已绑定且原平台账号仍启用时进入工作台。“平台账号登录”始终只验证本平台账号密码，不自动绑定微信；只有用户明确选择“绑定已有平台账号到此微信”并验证原密码后，才绑定原 `users.id`，保留原权限、相册和数据，也可取消返回密码登录。AppSecret 仅在服务端环境变量，不进代码包。相册读取范围与操作能力由服务端返回的列表和 `canManage` 决定；`admin` 管理全部，`operator`/`member` 可新建自己的相册、但只能修改/上传/删除自己创建的相册，`viewer` 只能查看。活动库支持名称、城市、类别、简介及标签关键词搜索。
- 新用户申请：可主动选择微信申请，或设置平台账号密码后申请平台账号；后者不依赖微信登录服务。两者均填写真实姓名、自填联系方式、城市和机构，阅读并同意隐私指引，等待总部核实、设置权限；申请成功不会建立工作台登录态。联系方式仅供人工核实，不表示微信已验证手机号。已有账号应直接登录，避免重复申请；总部明确选择原账号匹配或确认新建，不按姓名和联系方式自动合并。
- 客户：点击某个相册的分享卡片 → 匿名查看该相册、照片和视频；符合交付格式的素材可保存到系统相册。分享路径指向 `pages/album/index?id=...`，不经过主办方登录。
- 公开浏览只请求公开活动库和精彩案例，不调用账号或相册列表，也不获取微信身份；显式登录页仍可“继续浏览公开活动与案例”。活动库和精彩案例以封面卡片展示，游客可免登录预览已发布内容；再次分享直接进入同一条公开内容详情，不自动发起微信登录或申请。完整执行 SOP、真实 PDF 下载需登录，下载还需账号具有 SOP 下载权限且该活动允许下载。活动/案例详情发起登录时，仅允许白名单内的原详情 `returnTo`；登录后移除 `guest=1` 并重新载入详情及权限，不自动执行下载，也不接受管理页或外部网址回跳。PDF 保存到小程序本地后打开文档菜单。精彩案例的照片/MP4 保存入口放在每张素材卡片顶部，文档可下载打开；这些操作均先走原 H5 的登录鉴权与下载审计，游客点击下载提示登录。案例视频另有“竖屏全屏播放”按钮，显式以竖屏方向进入全屏（上线前仍须 iPhone/安卓真机验收）。外部链接素材仍未在小程序内实现下载。原 H5 的编辑/审核、评论及总部权限/访问日志尚未完整迁入。

活动相册的 `canManage` 由服务端按创建者 ID 与当前角色计算；小程序和 H5 只按该结果显示操作入口，不能靠隐藏按钮代替服务端鉴权。登录后的相册读取范围也以服务端列表为准，不在小程序内自行扩大；普通只读账号不会收到创建者 ID 或访问审计摘要。没有创建者记录的历史相册仅总部管理员能管理。公开分享仍只显示已发布且允许分享的指定相册，客户免登录保存边界不变。

微信身份只负责识别小程序用户，角色、相册归属、停用状态和 SOP 下载权限仍以平台 `users.id` 为准。新微信申请和 H5 待审账号可由总部合并到同一条用户记录，禁止按昵称或自填联系方式自动合并；老的 `disabled` 账号不会自动视为待审。主动退出后不会立刻自动重登，用户可显式选择“使用微信登录”。总部管理员不开放微信免密绑定，使用原账号密码登录。申请页显示与总部一致的 12 位微信核对码，方便人工核实，但核对码本身不代替身份审核。总部重置密码会撤销该账号已有的微信绑定和旧会话。H5 浏览器目前仍用账号/密码，但已经共用同一用户 ID、待审状态和总部权限；网页端的微信自动授权属于另一条协议，不能复用小程序 `wx.login`。

登录成功后仅保存平台 token、用户权限、服务端登录方法和有效期，不保存密码。有效会话再次打开或返回前台时，经服务端复核后直接进入工作台；入口重复触发生命周期时合并进行中的复核。普通用户曾主动微信登录或明确绑定、且有效期剩余不超过 24 小时时，可带原有效 Bearer 静默续验同一 `users.id`；已经过期、被撤销、旧方法未知或总部管理员会话不自动获取微信身份。续验临时网络失败时保留原有效会话，短暂退避期间仍逐次复核服务端权限。过期后显示上次明确使用的登录方式提示，须重新显式登录，不会自动重新绑定。主动退出立即清本地登录态并取消在途恢复；晚到的新 token 精确撤销，不能重新登录或覆盖之后登录的另一个账号。游客入口、公开相册分享继续绕过上述身份恢复。

## 客户保存的实际边界

- 小程序相册和单素材分享可匿名打开；点击“保存到手机相册”后，先复核相册仍已发布且允许分享，再经现有公开接口记录下载，随后从已登记的项目 CDN 下载并调用微信保存照片/视频接口，不把临时 TOS 签名地址展示给客户。
- 只有项目 CDN 上的 JPG/PNG 和有明确文件大小、且不超过 200 MB 的 MP4，才显示为可直接保存。MOV/HEIC/SVG 等原件不能据此宣称可一键保存；按钮会说明原因。新上传视频由服务端生成交付版 MP4（接口已于 2026-09-22 随后端部署上线），旧素材需补交付版。
- 2026-09-22 只读核对现网一个已发布相册：1 张 JPG、36 个视频，其中仅 2 个 MP4，其余 34 个为 MOV。1 张照片和 2 个 MP4 的 CDN `HEAD` 返回 200、类型与长度正确；这只证明交付文件可访问，**尚不等于已在 iPhone/安卓/鸿蒙真机完成保存验收**。该相册已于 2026-09-22 完成交付版替换，36 个视频均为带首帧的 MP4。

## 新上传的处理边界

1. 小程序 `wx.chooseMedia` 选择照片/视频后，本机调用 `wx.compressImage` / `wx.compressVideo`。只上传压缩后的临时文件；视频仍达到或超过 190MiB（199,229,440 字节）时要求分段，不传原片。超过200MB原片能否压入边界，须以真实手机的微信压缩结果为准，不承诺任意大文件都能成功。上传最多等待10分钟；弱网超时需重新上传，尚无原生断点续传。
2. `wx.uploadFile` 向鉴权入口传输，上传域名须在该 AppID 配置。后台单队列生成 H.264/yuv420p MP4、原片有声音时保留 AAC、`faststart` 和真实 JPEG 封面；目标175MiB、成片严格小于190MiB，最长120分钟，按码率调整分辨率/帧率。服务端有限总接收时间15分钟，为小程序10分钟传输留余量。完整标准以[视频上传与分享标准](../VIDEO_UPLOAD_STANDARD.md)为准。
3. 传输100%只代表文件送达。真实文件、音画完整性、TOS成片与封面检查及数据库写入成功后才发布；任务ready记录落盘后清理本次临时原片。失败保留可重试原片；中断的半截文件立即清理。小程序按账号和相册保存任务编号，断网退避续查、返回恢复，失败可重试；处理中禁止另传第二段视频，分享与客户预览需等待任务完成。状态记录不保存token或源文件路径。
4. 服务端依赖 `ffmpeg`/`ffprobe` 和 TOS，单队列与磁盘预算保护运行资源。生产发布依照[受控发布流程](../DEPLOYMENT.md)，核对 GitHub SHA、CI、运行文件、健康检查和业务数据；磁盘可用空间以每次发布前的实际检查为准。
