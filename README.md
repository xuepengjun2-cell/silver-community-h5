# 同城银发社群 H5 展示与后台管理

## 生产代码源与发布边界

生产环境以 GitHub `main` 的明确 commit 为唯一代码源。服务器只保留运行时环境、数据库、上传临时目录和 PM2 进程，不直接在服务器编辑业务代码；TOS/CDN 只接收从 GitHub commit 构建并校验过的静态发布包。

活动相册的图片、视频和上传会话数据属于生产运行时数据，不随代码发布覆盖。代码发布前必须完成服务器/TOS/CDN 备份，发布后必须做公网入口、API 健康、登录权限和活动相册链路验收。

这是一个轻量可运行原型，用于给银发社群主理人交付活动展示窗口。

## 启动

```bash
./start.sh
```

也可以用项目内置的 npm：

```bash
./npm install
./npm start
```

如果本机已安装 Node.js，也可以运行：

```bash
node server.js
```

打开：

- H5 前台：http://localhost:5174
- 后台管理：http://localhost:5174/admin

## 已包含能力

- H5 活动列表与详情页
- 活动图片、内容、执行方案展示
- 后台登录
- 活动新增、编辑、删除、发布/草稿
- 图片上传
- 账号管理与权限角色

## 角色说明

- admin：活动与账号全权限
- operator：活动发布与编辑权限
- viewer：只读查看权限

当前版本是原型交付，不建议直接暴露到公网生产环境。
